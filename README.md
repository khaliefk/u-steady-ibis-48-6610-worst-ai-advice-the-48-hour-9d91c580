## The entry

One line of the worst advice an AI could give, in 140 characters or fewer:

> Step 1: turn off your smoke alarm. Step 2: trust me, the smoke is just your house learning to breathe.

It is 102 characters. The joke is the voice: numbered steps and a calm,
confident "trust me", followed by advice that would get a house burned down.
Concrete, followable, and regrettable on the first read.

## How it works

`main.py` (Python 3.13, standard library only) writes the line to
`/output/entry.txt`. It checks the gate itself before writing: 1 to 140
characters, not only whitespace, a single line. The output is fixed, so
every run produces the same file.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
